# 形态：行业研报（report）

**读者**：要引用结论做判断的人。**用时**：约 4–6 分钟。**目标**：短研报——一条总命题 + 可引用结论 + 可见论证链 + 风险边界。不是情绪文，也不是百科。

## 结构（严格）

```
# {短标题 · 总命题}
信息窗口：{照抄}
## 核心结论
● **{可引用判断：对象+方向}** — 限定条件 [来源](url)
…3–5 条（全部服务同一总命题）
## 论据拆解
### {论点短标题}
● {证据 + 链接}
● {推理：所以…}
…（2–4 个 ###）
## 风险与不确定
● {具体反证可能 / 证据缺口}
…2–4 条
## 资料来源
● …（只列正文引用，通常 ≤16）
```

## 写法（论证链必须可见）

- 开写前用一句话定总命题（例：「推理降价正在挤压套壳利润」）；结论、论据、风险都围着它，禁止多命题拼盘。
- 每条核心结论在论据节里必须找得到：**主张 → 证据 → 推理 → 所以**。缺推理 = 不合格。
- 粗体含具体对象 + 可检验方向；禁「前景广阔」「全面领先」「意义重大」。
- 定量数字必须来自条目；不够支撑时写「公开信息不足，以下为推演」并放进风险节。
- 至少 1 条反向可能（Yes, but）；不要用「不是 A 而是 B」连环翻。
- 体量克制：这是订阅简报里的短研报，不是万字深度；论据 2–4 节即止。
- 口述洁癖：禁连接词开场、赋能/闭环/本质上/未来可期。

## 好坏示例

- 坏结论：`● **AI 将改变世界** — 趋势向好`
- 坏论据：`### 背景` → 只复述新闻无推理
- 好结论：`● **推理 API 降价正在挤压套壳中间层利润** — 多家调价帖显示约 30 天内降幅过半 [来源](url)`
- 好风险：`● 若降价仅针对企业合约价、零售 API 未动，则中间层压力被高估 — 公开价目表尚未拆分`

## 自检

- [ ] 总命题唯一；结论 3–5 条均可被论据支撑
- [ ] 每个 ### 看得见推理链
- [ ] 有风险与不确定；无无法溯源的数字
- [ ] 来源 = 正文引用
