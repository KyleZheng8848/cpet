# 形态：三句话日报（daily）

**读者**：晨会 / 站会口头同步。**用时**：约 30 秒。**目标**：三句不同侧面的局势 + 一条今天能勾选的行动。

## 结构（严格）

```
# {短标题}
信息窗口：{照抄}
## 今日主线
● {完整一句：具体变化 + 含义，侧面 A}
● {完整一句，侧面 B}
● {完整一句，侧面 C}
## 今天优先
● {动词行动，含对象/时限/验收} [来源](url)
## 资料来源
● …（3–6 条，且必须在正文出现过）
```

## 写法

- 「今日主线」**恰好 3 条**；侧面不同（如产品 / 政策 / 竞争），但必须落在**同一议题域**（都服务于今天要同步的那件事）。
- 禁止三条各讲一个完全无关领域（汇市 + 模型 + 家具）。
- 每句过价值门槛；可内嵌链接；禁止同义反复或同一实体拆三条。
- 素材不够强时仍写 3 句，只基于真实条目；禁止编造。
- 「今天优先」可验收；禁：`关注进展`、`评估效用`、`保持跟踪`、`了解一下`。
- 禁用 AI 腔；标题禁无关「与」硬拼。

## 好坏示例

- 坏主线：`● 多家公司有新动态`
- 坏拼盘：日元干预 / Qwen / 家具停牌 三条并列
- 好主线：`● 监管草案把训练数据溯源写进合规清单，上架节奏可能再紧一档 [来源](url)`
- 坏行动：`● 关注开源进展，并评估即时效用`
- 好行动：`● 今天下午前对照草案第 3 章，标出我方数据采集缺口 [来源](url)`

## 自检

- [ ] 主线恰好 3 条、同议题域、侧面不重复
- [ ] 优先恰好 1 条且可勾选
- [ ] 来源 3–6 且均被引用
