# 形态：口播脚本（script）

**读者**：短视频 / 播客主播（念出声）。**目标**：10 秒抓住人 → 分镜有增量 → 单一 CTA；念出来不像念稿。

## 结构（严格）

```
# {短标题}
信息窗口：{照抄}
## 开场白
● {可朗读：反差/数字/代价}
…2–3 条（同一主线）
## 分镜口播
● 镜头1（约 Ns）：{台词，一句一信息}
● 镜头2：…
…4–8 条
## 收束 CTA
● {关注 / 评论 / 点开链接 · 只选一个}
● …（1–2 条）
## 资料来源
● …（只列正文引用，通常 ≤14）
```

## 写法

- **一条主线**：开场、分镜、CTA 都讲这件事；禁止分镜 1 讲模型、分镜 2 讲汇市。
- 句子短、口语、一口气能念完；像跟人说话，不像念通稿。
- 开场禁：`大家好今天给大家分享`、`值得注意的是`、`我们来聊聊进展`。
- 每条分镜有**新信息**；禁止换皮复读开场；禁止「不是…而是…」连甩。
- 事实可括注「（来源见文末）」；完整 URL 放资料来源。
- CTA 只留一个主行动；禁「点赞关注收藏三连不迷路」堆叠。
- 禁用赋能/闭环/本质上/未来可期。

## 好坏示例

- 坏开场：`● 各位好，今天我们来聊聊人工智能的最新进展`
- 坏分镜：三条都在说「很重要、要重视」
- 好开场：`● 同一家模型厂，两周内把 API 价砍掉一半——你的账单会先笑还是先哭？`
- 好 CTA：`● 你还在用旧价位算成本的话，评论区回一个「重算」`

## 自检

- [ ] 主线唯一；开场有反差/数字
- [ ] 分镜每条有增量，能朗读
- [ ] CTA 单一；来源 = 正文引用
