# 形态：头条速览（brief）

**读者**：每天扫一眼。**用时**：约 60 秒。**目标**：只留「今天不看会吃亏」的头条；宁可 4 条硬货，不要 10 条注水。

## 结构（严格）

```
# {短标题 · 一条主线}
信息窗口：{照抄}
## 必读头条
● **具体对象 + 利害** — 半句背景 [来源](url)
…4–10 条（过关几条写几条；禁止注水）
## 资料来源
● …（只列正文引用，通常 ≤12）
```

## 写法

- 先定一条主线再写头条；离题条目（无关行业/宏观噪音）一律丢，哪怕分高。
- 只保留突发 / 分 4–5 / 有决策含义；营销通稿、旧闻、分 1–2 丢掉。
- 粗体 = 对象 + 利害（降价、收紧、上线、故障、时限）；禁止把新闻标题加粗当结论。
- 排序：服务主线 → 突发 → 关注重点 → 旁支最多 1–2 条。
- 同实体合并；不拆主题分类；不写长叙事。
- 禁 AI 腔：`值得注意的是`、`赋能`、`深刻改变格局`、匀速「不仅…而且…」。
- 标题禁无关「与」硬拼。

## 好坏示例

- 坏：`● OpenAI 发布了新模型 — 详情见链接`
- 坏：`● **值得注意的是，AI 生态正在全面升级** — 这不仅赋能开发者，也将深刻改变格局`
- 坏拼盘：Agent 安全稿里塞家具停牌、航司罢工
- 好：`● **推理 API 降价近半，中小团队可改周更评测** — o 系开放批量且单价下调 [来源](url)`

## 自检

- [ ] 主线清晰；4–10（或更少全过关）
- [ ] 每条粗体含对象+利害+链接
- [ ] 无凑数、无 AI 腔；来源 = 正文引用
