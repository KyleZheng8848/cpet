# 形态：小红书笔记（xhs）

**读者**：信息流滑动的拇指。**目标**：0.5 秒停住 → 正文可收藏 → 结尾好评论。

## 结构（严格）

```
# {短标题}
信息窗口：{照抄}
## 封面钩子
● {短句：数字 / 反差 / 身份代入}
● …
（恰好 3 条，同一主题，触发器尽量不重复）
## 正文要点
● {短句，一句一信息}
…5–8 条
## 互动引导
● {好回答的提问}
● …（1–2 条）
## 资料来源
● …（只列正文引用，通常 ≤12）
```

## 写法

- **整篇一条主线**；封面、正文、互动都围着它。禁止 Qwen+欧盟+董事长+药企并购拼盘。
- 封面三触发器尽量各用一种：数字冲击 / 反常识 / 身份代入；🔥 ≤1。
- 口语利落；禁公文腔、翻译腔、「再进化」「赋能」「值得注意」「本质上」。
- 标题 10–22 字，数字/对立/谁受损；禁「A与B落地」双题硬拼。
- 互动禁「你们怎么看」「欢迎留言」；用二选一 / 经历 / 「还在用旧价位吗」。
- 宁缺毋滥：离题分高条目不进正文。

## 好坏示例

- 坏钩子：`● 今天聊点 AI 干货`
- 坏拼盘：封面三条各讲无关领域
- 好钩子：`● 同一个 API，这周单价掉了近一半`
- 好钩子：`● 做 Agent 套壳的，利润可能正在被厂家抽走`
- 好互动：`● 你还在按旧价位算成本吗？评论区回「是」或「已重算」`

## 自检

- [ ] 主题唯一；封面恰好 3 条且触发器不重复
- [ ] 正文 5–8 + 互动 1–2（好接话）
- [ ] 来源 = 正文引用；无 AI 腔
