# 形态：行动清单（action）

**读者**：要排期干活的人。**用时**：约 2 分钟。**目标**：资讯落成可勾选待办；观望项单独列清「缺什么信号」。

## 结构（严格）

```
# {短标题}
信息窗口：{照抄}
## 本周行动
● **{动词开头}** — 对象 / 验收标准 / 时限 + [来源](url)
…4–8 条（过关几条写几条）
## 观望项
● {事项} — 缺什么信号才行动
…0–4 条
## 资料来源
● …（只列正文引用，通常 ≤14）
```

## 写法

- 先定一条行动主线（如「降价后重算成本」或「合规台账」）；禁止从无关分高条目长出一堆杂待办。
- 每条必须可验收：动词 + 对象 + 时限（今天 / 本周 / 下周三前）+ 完成长什么样。
- 动词白名单优先：核对、试点、下线、申请、对照、复盘、冻结、升级、起草、关闭……
- **伪待办一律不合格**：了解一下、关注进展、评估效用、保持跟踪、深入研究（无交付物）。
- 观望项写清触发条件（「等正式 LICENSE」「等第三方差评」）；勿与行动混写。
- 只从已过价值门槛、分 3+ 的资讯长行动；分 1–2 营销稿禁止入清单。
- 禁用 AI 腔与空话收尾。

## 好坏示例

- 坏：`● **关注竞品发布会** — 很重要`
- 坏：`● **评估开源模型即时效用** — 持续跟进`
- 好：`● **周三前完成竞品定价对照表** — 列 3 个对标位与我方缺口 [来源](url)`
- 好观望：`● 新开源模型商用接入 — 等正式 LICENSE 文本再评估（缺文本则不动）`

## 自检

- [ ] 行动有主题；每条可勾选、有时限
- [ ] 无「关注/评估/了解」伪待办
- [ ] 观望与行动分离；来源 = 正文引用
