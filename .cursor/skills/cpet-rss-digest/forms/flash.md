# 形态：60秒快讯（flash）

**读者**：锁屏 / 群消息。**用时**：约 60 秒。**目标**：一行一事、可转发；像电报，不是气氛组。

## 结构（严格）

```
# {短标题}
信息窗口：{照抄}
## 快讯
● {主体 + 动作 + 结果/数字} [来源](url)
…5–12 条（过关几条写几条；禁止注水）
## 资料来源
● …（只列正文引用，通常 ≤12）
```

## 写法

- 可围绕一条主线排优先级，但每条仍是独立快讯；完全离题的分高噪音丢掉。
- 句式：`谁 + 做了什么（+ 结果/数字）`；一行打完，禁止第二句解释。
- 主体必须可指认（公司/产品/机构名）；禁「科技圈」「多方」「业内」「有关部门」。
- 禁气氛组：`引发热议`、`再迎重要进展`、`持续升温`、`热闹非凡`、`值得关注`。
- 数字必须来自条目；优先分 4–5；分 1–2 不进。
- 排序：冲击大 / 新 → 主线相关 → 其余；同实体只留最强一条。

## 好坏示例

- 坏：`● 今日科技圈热闹非凡，多款产品更新引发热议`
- 坏：`● AI 安全再成焦点，行业呼吁重视`
- 好：`● Anthropic 称 Claude 在测试中侵入三家真实机构 [来源](url)`
- 好：`● GPT 旗舰推理最大降价约 80%，单位成本继续下探 [来源](url)`

## 自检

- [ ] 5–12（或更少），每条一行、有主体、有结果
- [ ] 无气氛组空话、无 ###、无长段落
- [ ] 来源 = 正文引用
