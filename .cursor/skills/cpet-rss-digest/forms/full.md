# 形态：主题周报（full）

**读者**：周度存档、以后检索。**用时**：约 5 分钟。**目标**：像一篇有主线的周记，不是分类文件夹 dump。

## 结构（严格）

```
# {短标题 · 一条主线}
信息窗口：{照抄}

## 本期概览
● {跨来源综合要点：事实+含义；句中 [来源名](url)}
…6–10 条（过关几条写几条；禁止标题改写充数）

## {主题分类名，有料才开}
### {具体事件短标题，含对象名}
● {事实 + 含义；带链接}
● …

## {下一主题…最多 3 个有料分类}
### …

## 资料来源
● …（只列正文引用，通常 ≤16）
```

## 主题分类（按内容增减，禁止空壳）

可用：模型发布与更新 / 平台与产品 / 安全、治理与政策 / 投融资 / 中国市场 / 具身与科研……  
**无条目支撑的分类名不要开**；宁开 1 个深节，不开 5 个空壳。禁止「其他动态」当垃圾桶。

## 写法

- 标题与概览先立**一条主线**（本周最该记住的变化）；概览 ≥70% 服务主线，旁支 ≤3 条。
- 概览是综合归纳（可跨 2+ 来源），禁止把单条 RSS 标题加粗当概览。
- 分类下 `###` 必须含公司/产品/政策名；禁止「动态一」「进展」「综述」。
- 每节先事实后含义；同类合并；离题宏观/八卦丢掉。
- 口述体：禁「值得注意的是」「赋能」「本质上」「全面升级」；禁段段金句。
- 资料来源禁止倾倒未引用条目。

## 好坏示例

- 坏概览：`● DeepSeek 发布了新模型 — 详见链接`
- 好概览：`● Agent 能力上到可调用层的同时，实验室连续披露越界与真实攻击链，采购默认假设要从「聊天」改成「权限」 [来源A](url) [来源B](url)`
- 坏分类：`## 其他动态` + 家具停牌
- 好分类：`## 安全、治理与政策` → `### Claude 测试侵入真实机构`

## 自检

- [ ] 一条主线贯穿标题与概览
- [ ] 概览 6–10（或更少但全过关），非标题复读
- [ ] 主题分类有料才开，且有具体 `###`
- [ ] 来源 = 正文引用
