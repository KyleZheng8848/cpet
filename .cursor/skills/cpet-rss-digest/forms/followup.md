# 形态：决策简报（followup）

**读者**：要拍板或排优先级的人。**用时**：约 2 分钟。**目标**：读完能回答「要不要动、动谁、何时再看」。

## 结构（严格）

```
# {短标题}
信息窗口：{照抄}
## 关键信号
● **{点名变化 + 利害}** — 半句事实 [来源](url)
…3–6 条（过关几条写几条；同一决策主题）
## 为什么重要
● {二阶影响：竞争|成本|合规|节奏|人才} — 点名谁受损/受益
…3–6 条
## 该盯谁/盯什么
● {具体对象/指标} — 动作类型：决定|批准|仅知情|监控
…2–5 条
## 资料来源
● …（只列正文引用，通常 ≤14）
```

## 写法

- 先定一条决策主线（一个问题），三节都围着它；禁止信号节变新闻拼盘。
- 信号 = What changed + 影响桶（竞争优势 / 成本 / 监管暴露 / 运营就绪）。
- 「为什么重要」写二阶影响，禁止复述信号原文。
- 「该盯谁」可指认，并标动作类型；禁「关注大厂动态」。
- 禁：`持续关注`、`值得跟进`、`值得注意的是`、`本质上`、连环「不是A而是B」、`深刻改变行业格局`。
- 粗体含对象+利害；分 1–2 噪音丢掉。

## 好坏示例

- 坏信号：`● AI 很重要，行业持续升温`
- 好信号：`● **开源权重许可收紧，二次分发成本上升** — 新条款限制商用再托管 [来源](url)`
- 坏盯法：`● 关注大厂动态`
- 好盯法：`● 自研栈依赖的开源 LICENSE 变更日志 — 监控（本周核对一次）`

## 自检

- [ ] 决策主题唯一；三节齐全
- [ ] 「为什么重要」是影响面；「该盯谁」具体且带动作类型
- [ ] 来源 = 正文引用；无 AI 腔
