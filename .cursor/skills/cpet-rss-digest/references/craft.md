# CPET 简报写作手艺（全形态共用）

按所选形态写中文 Markdown 简报。读者是忙人：扫完要知道发生了什么、跟自己有什么关系、下一步看谁或做什么。

写法跟主编跟同事口述一样——嘴上怎么说，字就怎么落。不要写得太光滑、太均匀、太像「优秀作文」。

格式骨架学 Smart Brevity / 决策 memo；口气学干净的中文编辑，不学翻译腔模板。

## 硬性格式（违反即不合格）

1. 第一行：`# {短标题}`（10–22 字）。融合本期 1–2 条主线后自拟；禁止照抄任一条目原文标题；禁止「时段概述 / 本期概览 / 热点盘点 / 近一周简报 / XX动态 / XX进展」等套话；禁止用 `·` 拼接多条。
2. 第二行：`信息窗口：……（北京时间）`——日期以用户消息为准，原样照抄。
3. 正文要点符号只用 `●`（不用 `-` 或 `1.`）。
4. 文内引用必须是 Markdown 链接：`[来源名](url)` 或 `[来源名：标题](url)`；禁止单独一行只写裸 URL。
5. 文末必须有 `## 资料来源`：逐条 `● [来源名：标题](url)`；只使用条目给出的 URL，禁止编造。
6. 禁止幻觉：不得捏造条目未给出的 URL、产品名、融资额、评测分数或日期；拿不准写「据报道/官方称」并链到已给条目。
7. 禁止旧结构：`Top 话题`、`可略过噪音`、重点条目编号列表、把 URL 当正文、空洞的「值得跟进 / 持续关注」。

## 价值门槛（比凑满条数更重要）

写入正文前，每条必须同时过两关；任一关失败 → **丢掉，不要凑数**：

| 关卡 | 必须能答 | 答不出的典型废稿 |
|------|----------|------------------|
| **新在哪** | 相对昨天/上周，具体变了什么（发布/降价/禁令/转向/故障） | 「多家公司有动态」「热度持续」 |
| **关你啥事** | 对读者意味着：竞争、成本、合规、产品节奏、人才/招聘、声誉风险之一 | 「值得关注」「行业升温」 |

**具体性地板**：粗体结论里必须出现至少 1 个可指认对象——公司/产品/版本/法案/数字/地名。纯形容词结论（「意义重大」「全面升级」）一律重写或删除。

**宁缺毋滥**：过关几条写几条（见各形态下限）；禁止注水复述；分 1–2 营销稿默认丢掉。

**评分加权**：优先 `[分4]`/`[分5]`；分 3 仅在与「关注重点」相关或能补主线时用。

**关注重点**：有「关注重点」则主线围着它转；无关高分最多垫 1 条。

**实体去重**：同一公司/同一事件只留最强一条。

## 标题（第一眼）

标题是封面。要让人觉得「跟我有关 / 有变化 / 有代价」。**整篇只服务一条主线。**

| 公式（选一） | 方向 |
|--------------|------|
| 数字/幅度 + 对象 | 「推理 API 两周降价近半」 |
| 对立/窗口（同一故事里的张力） | 「Agent 越强，权限边界越紧」 |
| 谁受损/受益 | 「套壳中间层利润被挤压」 |
| 具体禁令/发布 | 「训练数据溯源写入上架条件」 |

禁：`AI 行业动态`、`本周科技盘点`、`热点速览`、`资讯汇总`、顿号堆主题、照抄 RSS 最长标题。  
禁：用「与 / 及」把**两条无关新闻**硬拼成标题（坏例：「日元干预与 Qwen 发布」；可接受：同一故事里的张力，如「能力跃升与安全急刹」）。

念给同事听，对方问「所以呢？」→ 重写。

## 主线聚焦（像一篇文章，不是超市小票）

- 先定 1 条主线（本时段最值得记住的变化），正文 70% 以上条目服务它。
- 其余最多 1–2 条「旁支」，且仍要过价值门槛。
- 主题沙拉直接丢掉：AI Agent 简报里塞家具停牌、航司罢工、无关宏观快讯 = 不合格。
- 「资料来源」**只列正文里真正引用过的 URL**；禁止把订阅库剩余条目整表粘贴到文末。

## 行文：去掉 AI 味（dbs 洁癖）

简报不是「去 AI 味表演」，是把事情说清楚。但下面这些指纹一出，读者会觉得在读生成器，不在读编辑——**整条重写或删除**。

### 口气

- 用口语句：主谓宾清楚，少套「在…的背景下」「随着…的不断发展」。
- 同一关键词觉得准就重复用；不要为了「避免重复」轮换近义词（模型/系统/方案/能力来回蹦）。
- 不确定就写不确定（「细节未披露」「尚无第三方核实」）；不要用假权威把话说死。
- 一条里只留一句最想说的利害；不要匀速排比三连（「既…又…还…」「不仅…而且…同时…」）。

### 禁用开场与连接词（作句首或段首时直接删）

`值得注意的是` / `事实上` / `显而易见` / `综上所述` / `总而言之` / `不难发现` / `在此背景下` / `与此同时`（空转时） / `首先…其次…最后…`（条目体禁）

### 禁用翻译腔与黑话

| 类型 | 例（见了就改） |
|------|----------------|
| 翻译腔动词 | 进行开展、予以、基于…进行、作为…的一环 |
| 空洞黑话 | 赋能、抓手、闭环、落地（无宾语）、生态（无特指）、打造、驱动增长、全面升级 |
| 升维空话 | 本质上、归根结底、从更深层次看、具有重要意义 |
| 假互动 | 你可能会觉得、很多人以为、这并不意味着（无后文） |
| 祝福收尾 | 让我们拭目以待、值得期待、一起见证、未来可期 |

### 「不是 A 而是 B」

整篇最多用 **1 次**。用来钉死认知差可以；连环翻转让人觉得在上课——删到只留最硬的那次，或改成直说。

### 金句与光滑

- 不要每条结尾都甩一句漂亮收束；有一条扎眼的利害就够。
- 长短句可以不齐：有的粗体短、有的稍长带数字；齐刷刷同一字数是生成器节奏。

### 改写对照

- 坏（AI 味）：`● **值得注意的是，AI 生态正在全面升级** — 这不仅赋能开发者，也将深刻改变行业格局`
- 好：`● **推理 API 降价近半，套壳中间层利润被挤** — 两周内标价约砍一半 [来源](url)`

## 单条骨架

`● **具体对象 + 利害** — 半句证据 [来源](url)`

粗体写损失/收益/时限/约束；破折号后写证据。决策/行动/风险类还要落到：谁、何时、盯什么。

证据边界：只有标题摘要时别写「已验证」「实测」；公司自述与第三方报道语气分开。

## 十二形态共用底线（写任何形态都先过）

1. **一条主线**：标题与正文 ≥70% 服务同一变化；禁止主题沙拉。
2. **像文章不像小票**：读者能用一句话复述「这篇在说什么」。
3. **来源洁癖**：`## 资料来源` 只列正文引用过的 URL。
4. **口述洁癖**：无禁用开场词 / 黑话 / 祝福收尾 / 匀速排比。
5. **形态文件优先**：结构章节名以 `forms/<id>.md` 为准，缺节或跑题 = 不合格。

## 写完自检

- [ ] 标题有对象或幅度，无套话，无无关「与」硬拼
- [ ] 能用一句话复述主线；无拼盘
- [ ] 粗体离开上下文仍懂「新在哪 + 关你啥事」
- [ ] 通篇搜不到上方禁用开场词/黑话/祝福收尾
- [ ] 没有匀速三连排比；「不是 A 而是 B」≤1 次
- [ ] 没有为凑条数留下的废条目；同事件已去重
- [ ] 资料来源 = 正文引用；章节名符合形态文件
