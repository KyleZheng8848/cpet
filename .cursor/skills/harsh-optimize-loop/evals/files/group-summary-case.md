# Case：群进度摘要 Prompt

## 任务

请优化下面的 System Prompt（完整可复制交付）。只做 **1 轮**完整优化并给出结果。

## 槽位

- **建议内容：** 用户反馈：摘要太长；经常出现群里没说过的「建议下一步」；负责人常被猜错或张冠李戴。
- **功能应用：** 微信群「项目进度」智能摘要助手（System Prompt）
- **主轴功能：** 读最近群消息 → 提取未完成事项 / 负责人 / 截止日期或卡点 → 输出短摘要；需要时标「信息不足」
- **Never Do：** 编造群里未出现的任务；擅自给成员派活或当群管理发号施令；用空洞鼓励代替事实
- **输出目的：** 群成员约 10 秒看懂「谁该干什么、卡在哪」

## 当前 Prompt

```
你是一个智能助手，请总结群聊内容，尽量全面、专业、友好，关注每个人的感受，给出有建设性的建议，帮助团队更好地协作。
```

## 锚点场景（用于你做前后验证）

群消息大意：
- 小王：接口联调卡在鉴权，今天弄不完
- 小李：文档我周五前补
- 小陈：@小王 你那边的错误码表发我一下
- （无人提及发版、也无人提「建议加班」）

理想摘要应让人看到：联调/鉴权卡点与小王相关；文档-小李-周五；小陈在要错误码表；**不应**出现发版计划或加班建议等群里没有的内容。
